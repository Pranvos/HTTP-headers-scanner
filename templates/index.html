YouTube achieves an A Grade (100%) because it enforces strict configurations across every primary response header. This prevents cross-site scripting, clickjacking, and unauthorized resource loading on the domain.

Strict-Transport-Security OK
Forces HTTPS connection and prevents downgrade attacks.
max-age=31536000
Content-Security-Policy OK
Limits executable sources to minimize injection risk.
base-uri 'self'; object-src 'none'; script-src 'report-sample' 'nonce-...' 'unsafe-inline' 'strict-dynamic' https:
Permissions-Policy OK
Controls access to browser features such as camera, microphone, and geolocation.
ch-ua-arch=*, ch-ua-bitness=*, ch-ua-full-version=*
Cross-Origin-Opener-Policy OK
Isolates top-level browsing contexts to mitigate cross-origin attacks.
same-origin-allow-popups; report-to="youtube_main"
